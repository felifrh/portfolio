Interface & Realtime

inside a server

An AR application that takes you on a journey through the internet, from node to node.

Year
2020 – 2021
Context
Interactive Media course, 3rd semester, University of Applied Sciences Würzburg
Team
solo project
Role
concept, development, physical build
Tools
Unity, Vuforia, Processing, Fadecandy, Neopixel LEDs

01 / Nodes

Inside a Server is an interactive AR application that invites users to dive into the World Wide Web, represented by nodes. These LED-illuminated shapes on a wall contain information about topics that occur on the internet: cookies, the volumes of data generated every day, and the possibility of manipulating elections with these data sets.

02 / Journey

A shape lights up on the wall. Users capture it with a tablet, and a particle shape appears that stands for the dissolution of the physical LED point. The particles contain information that can be clicked and explored. Once a node is solved, the particle shape dissolves and the next point lights up on the wall, so nobody gets lost inside the server.

The application conveys complex topics in a simple and exciting way by portioning them into individual dots to discover. It is an interplay between the physical LED wall, driven by Fadecandy and a Processing sketch, and the digital particle application built in Unity.
